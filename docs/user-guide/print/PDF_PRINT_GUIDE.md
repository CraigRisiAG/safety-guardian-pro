## 5. Operating Procedures

### Daily operations

1. Review Dashboard KPIs.
2. Update incidents and statuses.
3. Execute or prepare drills.
4. Confirm check-in readiness and staffing.

### Weekly operations

1. Export incidents data (CSV/JSON).
2. Export drill history and statistics.
3. Validate permissions and personnel mappings.
4. Review system logs and anomalies.

## 6. Troubleshooting

- Page appears stale: refresh browser to reload local data.
- Check-in unavailable: verify active drill state.
- Empty report exports: clear date filters and retry.
