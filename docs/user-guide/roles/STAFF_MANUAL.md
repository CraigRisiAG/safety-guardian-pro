# Safety Guardian Pro Staff Manual

## Purpose

This manual is for general staff using check-in and awareness features during safety events.

## Access level

Staff generally use:

- Login
- Public Safety Check-In
- In-drill check-in workflows

## What staff should do

- Keep profile and location information accurate.
- Respond quickly to active drill check-ins.
- Mark correct status (safe or needs assistance).
- Follow on-site instructions from safety officers.

## Check-in process during a drill

1. Open Safety Check-In from login or directed URL.
2. Search and select your name.
3. Set your status.
4. Submit check-in.
5. Update status if your situation changes.

## If no drill is active

The check-in page will show that check-in is currently unavailable. This is expected behavior.

## Common issues and fixes

- Name not listed: contact your admin to add or correct your personnel record.
- Cannot submit check-in: verify there is an active drill.
- Wrong status submitted: notify the safety officer immediately so it can be corrected.
